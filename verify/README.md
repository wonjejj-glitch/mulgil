# 물길 계산 엔진 검증

물길은 수리계산을 직접 만든 식으로 하지 않고 **표준 공개 엔진**을 그대로 씁니다 — 상수 OWA-EPANET 2.3.5(epanet-js), 하수·우수 EPA SWMM 5.2.4(미국 EPA 공식 소스를 WebAssembly 로 컴파일).
그래서 확인할 것은 **입력을 엔진에 제대로 넘기고, 결과를 제대로 읽어 보여 주는가** 입니다. 이 폴더는 그것을 공식 엔진과 직접 비교해 확인합니다.

## 무엇을 비교했나

| 구분 | 물길 쪽 (웹 화면과 같은 경로) | 공식 쪽 |
|---|---|---|
| 상수 | .inp 를 물길로 읽기 → 물길이 다시 쓴 입력 → EPANET(WASM) → 결과 표 | 원본 .inp 를 **공식 EPANET 2.3**(OWA 툴킷)과 **미국 EPA EPANET 2.2** 로 해석 |
| 상수 (내보내기) | 위와 같음 | 물길이 **내보낸 .inp** 를 공식 EPANET 2.3 으로 해석 — 다른 프로그램에서 열어도 같은 답인지 |
| 하수·우수 | .inp → SWMM 5.2.4(WASM) → 결과(.out) 읽기 | 같은 .inp 를 **EPA SWMM 5.2.4 공식 엔진**(swmm-toolkit)으로 해석 |

시험 관망: EPANET 공식 예제 **Net1·Net2·Net3**(펌프·배수지·제어 규칙 포함), 물길 상수 샘플, SWMM 시험 모델 6개(펌프·저류조·위어·LID·직접 유입 포함), 물길 하수 샘플, **물길 하수 자동 설계가 만든 입력**.
보고 시각마다 **모든 절점·관로**의 수압·수두·수요량·유량·유속(상수), 수심·수두·유량·유속과 흐름 연속 오차(하수)를 비교했습니다.

## 결론

- **상수**: 4개 관망, 비교한 값 약 3만 개 모두 공식 엔진과 사실상 같습니다. 가장 큰 차이는 Net3 유량 13,062 GPM 중 0.001 GPM(소수 다섯째 자리, 엔진 내부 단정밀도 반올림 수준)이고, 수압 차이는 0.00001 psi 이하입니다. 미국 EPA 의 이전 판(2.2)과도 같고, **물길이 내보낸 .inp 를 공식 EPANET 으로 열어도 같은 답**이 나옵니다.
- **하수·우수**: 8개 중 7개 모델은 수심·유량·유속이 소수 여섯째 자리까지 같고 흐름 연속 오차도 같습니다(물길 하수 자동 설계 입력 포함).
- **예외 1건 — LID(저영향개발 시설) 모델**: 평균 차이는 0.0007 cfs 로 작지만, 첨두 시각에 유량이 최대 3.3% 다릅니다(연속 오차 0.294% / 0.293%). LID 계산은 반복 풀이라 컴파일 방식(브라우저용 WASM ↔ PC 용 네이티브)의 부동소수점 차이에 민감한 것으로 보입니다. 물길은 LID 를 만들지 않고 들어 있는 파일을 열어 해석만 하므로, LID 가 있는 파일은 결과를 공식 SWMM 으로도 확인하길 권합니다.
