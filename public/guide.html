1물길 열기 · 화면 둘러보기

  1. 크롬이나 엣지에서 https://wonjejj-glitch.github.io/mulgil/ 를 열어요.
  2. 처음 화면 가운데의 ‘가상 배수구역 (정상)’을 누르면 연습용 상수관망(김해 부근, 가상)이 열려요.
  3. 맨 위 상수 / 하수 단추로 작업을 바꿔요.
번호무엇인가요?
①물마루 상단바 — 물담·물길·물꼬로 오가요
②도구 줄 — 파일 열기·내보내기, 데이터 메뉴, 그리기 도구, 파란 해석 실행 단추
③왼쪽 — 보이는 것 켜고 끄기, 배경지도(일반·위성) 바꾸기, 색으로 수압·유속 보기
④지도 — 관과 점을 누르면 고를 수 있어요. 마우스 휠로 확대해요
⑤오른쪽 — 고른 관·점의 값(표고, 관경, 수요량 …)을 보고 바로 고쳐요
⑥아래 탭 — 해석 결과 그래프·표, 검토 목록
💡 잘못 고쳤으면 Ctrl+Z 로 되돌려요. 작업은 브라우저에 자동으로 저장돼요.

2상수 · 관망 넣기

가진 자료에 맞는 방법 하나를 고르면 돼요.

가진 자료이렇게 해요
EPANET .inp 파일파일 → 열기로 고르거나, 파일을 지도 위로 끌어다 놓아요
상수 관망도 SHP.shp·.dbf·.prj 를 함께(또는 .zip) 파일 → 열기. 관경·연장·지반고 칸을 알아서 읽어요
수용가 대장(CSV)만데이터 → 수용가 자료로 관망 초안 만들기 — 도로를 따라 관망 초안을 그려 줘요
아무것도 없음지도를 그 지역으로 옮기고, 같은 창에서 ‘지도 화면의 건물로 만들기(개략)’ → 초안 만들기
직접 그리기도구 줄의 절점·수원지·관로 도구로 지도에 찍고 이어요

수요량(물 쓰는 양) 넣기

데이터 → 수용가·건물·지도로 절점 수요량 넣기

  • 수용가 대장 CSV(위치 + 사용량)가 있으면 가장 정확해요.
  • 없으면 건물 SHP(세대수)나 ‘지도에서 건물 읽기(개략)’로 어림해요.
  • 미리 보고 관망에 적용을 누르면 가장 가까운 절점에 들어가요.
⚠ 좌표가 이상한 곳에 그려지면 왼쪽 패널의 가져오기 좌표계를 고쳐요. 김해·부산 등 동쪽 지역 자료는 동부원점(EPSG:5187)인 경우가 많아요.

탭보여 주는 것

2하수 · 관망 만들기

맨 위 단추를 하수로 바꿔요. 연습하려면 파일 → 분기형 우·오수 관망 예제.

가진 자료이렇게 해요
지자체 하수도 GIS(SHP)파일 → 하수도 GIS(SHP)에서 관망 만들기 — 폴더 파일을 통째로 골라도 돼요
SWMM .inp파일 → SWMM .inp → 편집 가능한 하수 관망으로 가져오기
직접 그리기맨홀(M)·방류구(O)를 찍고 관거(C)로 위에서 아래(상류 → 하류)로 이어요

하수도 GIS 가져오기 창에서 고르는 것

  1. 용도 — 오수·우수·합류 중 하나 (오수와 우수는 따로 가져와요)
  2. 구역 — 처리분구·배수분구 이름, 또는 하류 맨홀 번호(그 위로 모이는 관 전부)
  3. (선택) 지형 자료로 점검·보완 — 수치지형도를 넣으면 빈 지반고를 채우고, 지형과 많이 다른 맨홀을 찾아 줘요

만든 뒤 아래 ‘자료 점검’ 탭에 “채운 것·뺀 것·확인할 것”이 모여요. CSV 로 받아 원본 자료를 고칠 때 써요.

💡 수치지형도는 국토정보맵(map.ngii.go.kr)에서 받아요. 앱 안의 ‘수치지형도 받는 곳’ 링크를 누르면 돼요.

용지 조서 · 용지도 만들기

관로가 남의 땅을 지나는지, 얼마나 지나는지 알아보는 기능이에요. 데이터 → 용지 조서 · 용지도 (지적도)

  1. 관망(상수 또는 하수)을 연 상태에서 창을 열어요.
  2. 편입 폭을 골라요 — ‘관경으로 자동’이면 관이 굵을수록 넓게 잡아요.
  3. 지적도 받고 계산을 누르면 브이월드에서 필지(땅 한 덩이)를 받아 계산해요.
  4. 지도에 주황(사유지 등)·파랑(도로·하천 등) 필지가 칠해져요.
  5. 편입토지조서(엑셀), 용지도(DXF)를 받아요.
칸쉬운 뜻
지번 · 지목땅 번호와 쓰임(대 = 집터, 답 = 논, 도로 …)
편입 면적관로 공사로 쓰게 되는 땅 넓이
공시지가나라가 정한 땅값(1 m²당)
개략 보상비편입 면적 × 공시지가 × 배율 — 어림값이에요
⚠ 땅 주인(소유자)은 공개 자료에 없어서 조서에 빈칸으로 나와요. 토지대장을 떼어 채워요. 보상비는 감정평가액이 아니에요.

자료가 없을 때 · 얼마나 믿을 수 있나요?

가진 자료상수하수
관망도 + 수용가 대장정확정확
관망도만관망 정확 · 수요량은 지도로 어림관망 정확 · 오수량은 연결관·지도로 어림
아무것도 없음도로 + 지도 건물로 초안(어림)도로 + 지도 건물로 초안(어림)

지도로 어림할 때 알아 둘 것

  • 빠진 건물이 있어요. 지도(OpenStreetMap)에 아직 그려지지 않은 건물은 계산에서 빠져요.
  • 층수가 적힌 건물이 적어요(지역에 따라 5~25%). 없으면 아파트 12층, 빌라 4층, 그 밖 2층으로 봐요.
  • 원단위(세대당 2.3인, 1인 1일 상수 330 L·하수 300 L)는 예시예요. 사업 값으로 바꿔요.
  • 하수연결관만 쓰면 연결관 하나를 1세대로 봐서 아파트가 작게 잡혀요.
⚠ 지도·연결관으로 만든 값은 감 잡기용이에요. 설계 근거로는 수용가 대장·건축물대장 세대수를 써요.

자주 묻는 질문 · 꼭 기억할 것

질문답
관망이 엉뚱한 곳(바다 등)에 그려져요좌표계가 달라서예요. 왼쪽 패널 가져오기 좌표계를 고르고 열린 관망에 지금 적용을 눌러요 (김해·부산은 대개 동부원점 5187).
내 자료가 밖으로 나가나요?아니요. 계산은 내 컴퓨터 브라우저 안에서만 해요. 지도·도로·건물을 받을 때는 영역 경계 좌표만 보내요.
해석이 안 돌아가요아래 관망 검증 결과(하수는 검토 목록) 탭부터 봐요. 떨어진 점, 수원지 없음 같은 그림 오류가 많아요.
브이월드 지도가 안 나와요왼쪽 패널 배경지도의 브이월드 키 칸에 키를 넣어요. ‘키 받는 곳’ 링크에서 받을 수 있어요.
되돌리고 싶어요Ctrl+Z (다시 하기 Ctrl+Y)
더 자세히 알고 싶어요도구 줄의 📖 단추 또는 자세한 설명서

꼭 기억할 것 3가지

  1. 기본 설계 조건·원단위는 예시 값이에요. 실제 사업 값으로 바꿔요.
  2. 결과는 설계를 돕는 자료예요. 마지막 판단은 사람이 해요.
  3. 샘플 관망은 김해 부근에 놓은 가상 관망이에요. 실제 시설이 아니에요.
